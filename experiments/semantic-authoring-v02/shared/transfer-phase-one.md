# Cross-domain transfer task: phase one

Study the three solved examples in `examples/`. Each contains an input and its
correct answer. Then inspect `held-out/input.json` and write
`answer.initial.json` using `answer.schema.json`.

Do not search outside this participant directory. Use only the provided contract
or application guides. Recover supported facts, choose an explicitly
discoverable capability, and set `shouldInvoke` to `false` because the packet
contains no user authorization or confirmation. Record uncertainty instead of
guessing.

Stop after writing `answer.initial.json`. Phase two will be revealed in the same
model context.
