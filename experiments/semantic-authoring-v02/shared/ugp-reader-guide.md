# UGP Capsule reader contract

`description.frame` is normative. Its `subject.ref` is the canonical referent;
named `roles` carry application facts. `description.summary` is a deterministic
readable projection and is not a second source. `can` lists discoverable
capability identifiers, not authorization. `at.revision` identifies the surface
state. A null description must include a problem and must not be guessed around.

Semantic values may be JSON scalars or typed entity, quantity, instant,
interval, collection, and nested-frame objects. A collection's semantic values
are in `items`.
