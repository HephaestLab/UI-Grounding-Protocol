# Governance

UGP currently uses a maintainer-led model while the v0.1 protocol is being
validated.

Maintainers merge changes, cut releases, accept ADRs, and enforce conformance
and security gates. Protocol decisions should be recorded in public issues and
ADRs. Significant wire-format changes require an issue, alternatives considered,
conformance impact, and at least one maintainer approval.

As the contributor base grows, maintainership may be granted based on sustained,
constructive contributions and sound judgment across protocol, implementation,
and community work. Governance changes are proposed through a pull request to
this file.
