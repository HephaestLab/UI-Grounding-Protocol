# Security policy

UGP is pre-alpha. No released version is currently eligible for long-term
security support.

Please report suspected vulnerabilities privately through GitHub Security
Advisories for this repository. Do not open a public issue for a vulnerability
that could expose application data, cross authority boundaries, or produce
unsafe referent resolution.

Include affected commit or version, reproduction steps, impact, and any proposed
mitigation. The maintainers will acknowledge a report, assess severity, prepare
a coordinated fix, and credit the reporter unless anonymity is requested.
